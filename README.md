# 图论学习图编辑器

一个用于学习图论的单文件交互式图编辑器，无需安装任何依赖 —— **直接双击 `index.html` 用浏览器打开即可使用**。

- [功能特性](#四种模式快捷键-1-2-3-4) · [算法演示](#算法演示工具栏算法栏纯点击交互无快捷键冲突) · [快速编辑](#-快速编辑面板右上角开关默认锁定)
- 许可证：[MIT](LICENSE) · 回归测试：`node test.js`（25 项断言，从 index.html 提取真实代码验证）

## 四种模式（快捷键 `1` `2` `3` `4`）

| 模式 | 操作 |
|------|------|
| 👁 **查看** (`1`) | 节点**持续自动居中布局**（有界力模拟：拖拽时其余节点实时让位，**松手后自动归位对齐**）；在上方**算法栏**选择算法后**单击节点**运行：**BFS / DFS** 立即播放遍历动画；**Dijkstra / SPFA** 先单击起点、再单击终点，动画演示并高亮最短路径；**右键单击节点**固定/取消固定（粗描边）；空白处拖动平移，滚轮缩放 |
| ➕ **绘画** (`2`) | **点击空白处**新建节点（编号自动递增）；**从一个节点拖到另一个节点**新建边（拖出又拖回同一节点 = 自环；默认权重 1，画完可立即输入权重，支持负权重） |
| ✏️ **编辑** (`3`) | **点击节点**修改编号；**点击边**修改权重（支持负权重） |
| 🗑️ **删除** (`4`) | **点击节点**（连同其关联边）或**点击边**删除 |

## 工具栏布局（两行）

- **第一行 · 编辑图**：模式切换（快捷键 1-4）· 自动布局 · 撤销/重做 · 有向图开关 · 示例/导入/导出/清空/面板
- **第二行 · 算法演示台**：算法（BFS/DFS/Dijkstra/SPFA）· 播放速度（1×/2×/4×/⚡16×）· ⏭结尾

## 算法演示（工具栏"算法"栏，纯点击交互、无快捷键冲突）

1. 在工具栏选择算法（会自动切到查看模式）：**BFS** · **DFS** · **Dijkstra** · **SPFA**
2. 查看模式下**单击节点**运行：
   - **BFS / DFS**：逐步动画展示访问顺序与搜索树，左上角显示实时访问序列
   - **Dijkstra / SPFA**：单击起点后再单击终点，逐步演示松弛/入队过程，节点上显示当前最短距离，结束后**橙色高亮最短路径**并显示总距离与路径
3. `Esc` 或单击空白处取消；右键单击节点可固定布局锚点

### 播放速度与加速

- 工具栏**速度栏**：1× / 2× / 4× / ⚡16×，动画中途切换立即生效（默认 4×）
- **⏭ 结尾**按钮：一键跳过动画，立刻显示最终结果（大图演示必备）

**负权与负环行为**：

- 图中含负权边时 **Dijkstra 仍会照常运行**，但会弹出警告并在结果中标注 ⚠"结果可能错误"——方便课堂对比演示它为什么会错（可用 SPFA 对照验证）
- **SPFA 负环判定采用标准算法**：统计每个点的入队次数，当**某个点的入队次数达到 N（节点总数）**时才判定存在负权环；判定前动画完整、真实地展示入队/松弛过程（可用速度档 / ⏭结尾 加速）。判定后**红色高亮环上的节点与边**，并报告是哪个点、入队了多少次；起点=终点、是否选终点均安全
- **负自环**：起点可达的负自环会被识别为负环并红色标出（自环不进邻接表，主循环发现不了，由前置检查捕获）

## 通用操作

- **有向图 / 无向图**：工具栏开关切换，箭头与邻接矩阵随之变化；**有向→无向时自动合并双向重复边**（保留较小权重并提示），避免重叠边导致展示与编辑混乱
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`（最多 100 步）
- **平移与缩放**：查看模式空白处拖动 / 中键或右键拖动平移（右键在节点上按住拖动同样是平移）；滚轮缩放；停手后自动布局会重新居中
- **自动布局**：工具栏按钮，随时切回查看模式并重新居中排列
- **自动保存**：图形自动存入浏览器 `localStorage`，下次打开自动恢复（连接关系完整保留；打开后自动布局会重新居中排列节点——这是查看模式"时刻居中"的设计意图）
- **导入 / 导出**：JSON 格式，方便保存和分享习题（导出只含纯图数据，不含引擎内部状态）
- **示例**：一键载入一个 6 节点带权无向图

## 查看模式自动布局的实现说明

自研的**有界力导向模拟**，从机制上杜绝了常见力导向实现"节点被斥力崩飞再弹回来"的毛病：

1. 近距离斥力截断 + 单对斥力限幅 + 单节点合力限幅 —— 力永远有界
2. 速度阻尼 + 每帧位移上限 —— 节点每帧最多移动几个像素，物理上不可能弹射
3. 可视区软边界力 —— 越出画面的节点会被轻柔拉回
4. 向心引力使布局**时刻居中**；布局稳定后自动休眠省电，拖拽/松手/缩放立即唤醒

**稠密图专项优化**（减少边交叉、节点均匀分布）：

- **边-边中点斥力**：非相邻的边互相排斥，引导边的走线避开彼此（大图分帧计算保证帧率）
- **相邻/非相邻节点差异斥力**：相连节点允许靠近成簇，不相连的互相推开——簇间自然分离，交叉大幅减少
- **长程 1/d 斥力 + 最小间距强分离**：节点间距均匀，不扎堆、不重叠
- **理想边距随稠密度自适应拉长**：边越多，节点间距越大，给边留出走线空间
- **退火静止**：布局充分展开后逐步衰减所有力直到完全静止（自动休眠），拖拽/松手/缩放/改图立即唤醒重新排布

以上性质已通过数值仿真测试验证：固定种子稠密图（16 节点 40 边）**边交叉数从 133 降到 40（约 -70%）**、最近邻间距均匀（96~210）、多组随机种子稳定改善；画布外堆叠无弹射；固定节点严格不受力。

## 代码结构（单文件内的模块设计）

虽然是一个 HTML 文件，内部按模块组织，每个模块有清晰的小接口：

- **算法核心（纯函数）**：`computeOrder(graph, opts)` / `computeShortest(graph, opts)`，graph 是普通值入参，不读不写全局——可直接用普通对象对拍测试（`test.js` 即基于此）
- **GraphStore**：`commit(mutator)` 是所有图数据变更的唯一入口，收拢「快照 → 变异 → 校验 → 通知（撤销/面板/布局唤醒/存盘）」仪式，杜绝各调用点手工配对的遗漏类 bug
- **力引擎**：速度向量存引擎私有 Map，不污染图数据对象；序列化只导出纯图数据
- **bindGroup 适配器**：按钮组的独占高亮与回调绑定一处实现，CSS 类不兼做行为选择器

## 学习辅助面板（右侧）

- **邻接矩阵**：随图形实时更新，可在"权重"与 "0-1" 显示间切换；每行附带度数（有向图显示出度/入度，自环无向计 2 度）
- **边列表**：所有边及其权重一览
- **遍历 / 最短路演示**：选择算法后单击节点，动画逐步高亮访问顺序 / 松弛过程 / 最短路径，左上角显示实时状态

### ✏️ 快速编辑（面板右上角开关，默认锁定）

开启后面板变为可写，快速改图不必来回切换 GUI 模式；平时保持锁定防止误触。开启后：

- **邻接矩阵直接编辑**：点击任意格输入权重即可建边/改边；输入 0 或清空 = 删除边；对角线 = 自环（无向图自动对称）
- **列标题**：直接输入重命名节点，× 删除节点（连带关联边）；矩阵下方"＋ 添加节点"快速加节点
- **边列表**：每条边的端点（下拉框）、权重可直接修改，× 删除；底部"加边"一行快速添加新边
- 所有改动均可 `Ctrl+Z` 撤销，并与画布、统计完全同步

## 建议学习流程

1. 用**绘画模式**把课本上的图画出来（设成有向/无向、填上权重）
2. 对照右侧**邻接矩阵**验证手写的矩阵是否一致
3. 切到**查看模式**，算法栏选 BFS/DFS 单击节点看访问顺序；选 Dijkstra/SPFA 单击起点和终点看最短路，和手动模拟结果对照
4. 用**删除模式**删掉一条边，观察矩阵如何变化
